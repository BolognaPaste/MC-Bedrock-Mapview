      In-game pack

      Not seen yet

      For single-player and co-op worlds hosted on this PC. The pack also gives everyone in the world an in-game map: a minimap in the top-right corner (/minimap shows or hides it), and a big map while you hold the Map item it puts in hotbar slot 9 (press 9; use it to zoom) or after /map. It works on its own, without this app; with Content Log File on, this app gets the same data for its live map. No cheats are needed (like any behavior pack, it turns off achievements for that world).

      1. Install the add-on. Opening it imports it into Minecraft. Share the file with friends: the in-game map works for them even without this app.
      2. Turn on Settings > Creator > Content Log File in Minecraft. Leave "Content Log GUI" off, or the pack's messages show on screen.
      3. Add the pack to the world: Edit world, Behavior Packs, Available, Bedrock Map Live, Activate.
      4. Play. The app notices the world, builds its map if there is none yet, and opens it.

          Activity

            For plugin makers: protocol v1

            JSON over HTTP. Send Authorization: Bearer <key> with every request. The full description is in docs/live-protocol.md.

            • GET /v1/ping checks the app is running (no key needed)
            • POST /v1/hello starts a session: plugin, world and server names
            • POST /v1/push sends messages: players, chunk, event, world
            • POST /v1/bye ends the session
